# என் செல்ல மகளுக்காக… | டிஜிட்டல் நினைவுகள் காவியம் (Tamil Digital Memory Website)

ஒரு அப்பா தனது மகளுக்கு அன்புடன் பரிசாக வழங்கும் Production-Ready Cinematic Interactive Digital Memory Website. 
மகள் சிறு குழந்தையாக இருந்த காலத்திலிருந்து இன்று வரை உள்ள அனைத்து தருணங்களையும் ஒரு திரைப்பட உணர்வுடன் (Cinematic Interactive Story) மீண்டும் வாழ்ந்து பார்க்கும் வகையில் வடிவமைக்கப்பட்டுள்ளது.

---

## 🌟 சிறப்பம்சங்கள் (Key Features)

1. **100% தமிழ் பயனர் வடிவமைப்பு (Tamil-Only Visible Content)**:
   - வலைத்தளத்தின் அனைத்து headings, buttons, notifications, letter content மற்றும் UI கூறுகள் அனைத்தும் முழுமையான தமிழ் மொழியில் மட்டுமே அமைந்துள்ளன.
2. **திரைப்பட அனுபவத் தொடக்கம் (Cinematic Opening Screen)**:
   - “என் செல்ல மகளுக்காக…” மற்றும் “நாம் சேர்ந்து கடந்த ஆண்டுகளை மீண்டும் ஒருமுறை வாழ்ந்து பார்க்கலாம்…” எனும் மெதுவான typography animation மற்றும் “உள்ளே செல்லுங்கள் ↓” பொத்தான்.
3. **15 முக்கிய நினைவுகள் (15 Milestone Memories)**:
   - குழந்தைப் பருவம், தோள்களில் சுமந்த தருணம், குடும்ப மகிழ்வு, சிரிப்பு, செல்லக் கோபம், அழுகையும் அணைப்பும், முதல் நடை, பள்ளிப் பருவம், சிறப்பு விழா, பயணங்கள், சமீபத்திய புன்னகை, அப்பா-மகள் பிணைப்பு, இன்றைய மகள் வரை 15+ தருணங்கள்.
4. **உணர்ச்சிகளின் பயணம் (Emotional Spectrum)**:
   - சிரிப்பு → கோபம் → அழுகை → சமாதானம் → மீண்டும் சிரிப்பு என்ற வரிசையில் மாறும் பின்னணி மற்றும் வரிகள்.
5. **பக்கவாட்டு பயண நினைவுகள் (Horizontal Travel Scroll)**:
   - அப்பா மற்றும் மகள் சேர்ந்து பயணித்த இடங்களின் Horizontal Scroll புகைப்படக் காட்சியகம்.
6. **காலப்பயணம் (Visual Interactive Timeline)**:
   - "அந்த நாள்" முதல் "இன்றைய நாள்" வரை மாறும் புகைப்படக் காலக்கோடு.
7. **அப்பாவின் பார்வை (Father's Perspective)**:
   - “நான் உன்னை வளர்த்தேன் என்று நினைத்தேன்… ஆனால் உண்மையில்… நீதான் என்னை ஒரு அப்பாவாக மாற்றினாய்.” எனும் உணர்ச்சிப்பூர்வமான பிரிவு.
8. **நினைவுகளின் சுவர் (Interactive Photo Wall)**:
   - 3D parallax மற்றும் hover அனிமேஷனுடன் கூடிய 15+ புகைப்படங்களின் சுவர்.
9. **அப்பாவிடமிருந்து இறுதி செய்தி (Father's Climax Letter)**:
   - “அப்பாவிடமிருந்து…” தலைப்பில் தட்டச்சு அனிமேஷனுடன் (Typewriter animation) வரும் உருக்கமான தமிழ் கடிதம்.
10. **நேரலை தரவுத் திருத்தி (Live Tamil Data & Photo Editor Modal)**:
    - வலைத்தளத்திலேயே மிதக்கும் "நினைவுகளைத் திருத்து" பொத்தானை அழுத்தி புகைப்படங்களின் URL/கணினி புகைப்படங்கள், தலைப்புகள் மற்றும் அப்பாவின் செய்தியை எளிதாக மாற்றலாம்.
11. **பின்னணி மெல்லிசை (Ambient Soundscape Engine)**:
    - Web Audio API மூலம் இயங்கும் மென்மையான தாலாட்டு மெல்லிசை மற்றும் மிதக்கும் "இசை: இயக்கம் / நிறுத்தம்" கட்டுப்பாட்டு பொத்தான்.

## 🛠️ பயன்படுத்தப்பட்ட தொழில்நுட்பங்கள் (Tech Stack)

- **Frontend Core**: React 19 + Vite
- **Styling**: Vanilla CSS3 + Tailwind CSS v4 (Custom Glassmorphism, Gold Text Glow, Dark Palette)
- **Animations**: GSAP (GreenSock Animation Platform) + GSAP ScrollTrigger
- **Smooth Scroll**: Lenis Smooth Scroll
- **Icons**: Lucide React
- **Confetti**: Canvas Confetti
- **Audio**: Web Audio API Ambient Synthesizer
- **Typography**: Google Fonts (`Anek Tamil`, `Mukta Malar`, `Arima`)

## 🚀 திட்டத்தை இயக்குவது எப்படி? (Quick Start Guide)

### 1. Installation (நிறுவுதல்)

```bash
# திட்டத்தின் கோப்பகத்திற்குச் செல்லவும்
cd Frameo

# தேவையான தொகுப்புகளை நிறுவவும்
npm install
```

### 2. Run Project Locally (உள்ளூர் இயக்க முறை)

```bash
npm run dev
```
இயக்கிய பின் உங்கள் உலாவியில் (Browser) `http://localhost:5173` முகவரிக்குச் சென்று வலைத்தளத்தைக் காணலாம்.

### 3. Production Build (தயாரிப்பு உருவாக்க முறை)

```bash
npm run build
```
உருவாக்கப்பட்ட `dist/` கோப்புறையை எந்த ஒரு Web Server அல்லது Vercel / Netlify / GitHub Pages-லும் பதிவேற்றலாம்.

## 🖼️ புகைப்படங்கள் மற்றும் உரைகளை மாற்றுவது எப்படி? (How to Customize Content)

### முறை 1: வலைத்தளத்தின் நேரலை திருத்தி மூலமாக (Live UI Editor - Recommended)

1. வலைத்தளத்தை திறக்கவும்.
2. மேல் வலது மூலையில் உள்ள **"நினைவுகளைத் திருத்து"** பொத்தானைக் கிளிக் செய்யவும்.
3. எந்த நினைவின் புகைப்படத்தையும் URL மூலமாகவோ அல்லது **"கணினியிலிருந்து பதிவேற்று"** பொத்தான் மூலமாகவோ மாற்றி அமைக்கலாம்.
4. தமிழ் தலைப்புகள் மற்றும் **"அப்பாவின் செய்தி"** வரிகளைத் திருத்தி **"மாற்றங்களை சேமி"** பொத்தானைக் கிளிக் செய்யவும்.
5. இந்த மாற்றங்கள் உங்கள் Browser-ன் `localStorage`-ல் பாதுகாப்பாகச் சேமிக்கப்படும்.

---

### முறை 2: குறியீட்டு கோப்புகள் மூலமாக (Source Code Editing)

#### 1. புகைப்படங்களை மாற்றுவது எங்கே? (Where to replace photographs)

- உங்கள் சொந்தப் புகைப்படங்களை `public/images/memories/` கோப்பகத்தில் சேர்க்கவும் (எ.கா: `memory-01.jpg`, `memory-[#01-15].jpg`).
- அல்லது `src/data/memoriesData.js` கோப்பைத் திறந்து `image` அல்லது `customImage` மதிப்பில் உங்கள் புகைப்படப் பாதையை மாற்றலாம்:

```javascript
// src/data/memoriesData.js
{
  id: 1,
  stage: 'குழந்தைப் பருவம்',
  title: 'ஒரு சிறிய கையை பிடித்த அந்த நாள்…',
  subtitle: 'அன்றிலிருந்து என் உலகமே கொஞ்சம் மாறிவிட்டது.',
  image: '/images/memories/memory-01.jpg', // உங்கள் புகைப்படத்தின் பாதை
  story: 'உன் பிஞ்சு விரல் என் பெருவிரலை இறுக்கிப் பிடித்தபோது...'
}
```

#### 2. தமிழ் வரிகள் & தலைப்புகளை மாற்றுவது எங்கே? (Where to edit Tamil captions)

- `src/data/memoriesData.js` கோப்பில் உள்ள `initialMemories`, `emotionalSpectrumData`, `travelData`, மற்றும் `timelineStages` ஆகியவற்றில் அனைத்துத் தமிழ் உரைகளும் உள்ளன.

#### 3. அப்பாவின் இறுதிச் செய்தியை மாற்றுவது எங்கே? (Where to edit Father's Final Message)

- `src/data/memoriesData.js` கோப்பில் உள்ள `fatherLetterText` மாறியில் நீங்கள் விரும்பும் தமிழ் வரிகளைத் திருத்தலாம்:

```javascript
export const fatherLetterText = `என் செல்ல மகளே,

நீ என் கைகளில் முதன்முதலாக வந்த அந்த நாளிலிருந்து,
என் வாழ்க்கையில் ஒரு புதிய உலகம் தொடங்கியது...

என்றும் அன்புடன்,
அப்பா.`;
```
